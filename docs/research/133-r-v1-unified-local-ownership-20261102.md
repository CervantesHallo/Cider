# R v1：从本地构造开始统一实验资源所有权

接续[132](132-r-v1-renderer-reparent-20261102.md)。此前前端只在初始 foreign HWND 时建立导出 CAContext。本次采用一个**仅供实验的策略**：`WINEMAC_EXPERIMENTAL_REMOTE_RENDERER=1` 时，本地初始窗口也从构造开始使用同一个既有导出 owner／known-ticket／只读许可路径，避免以后移到其他进程根窗口时中途替换设备、交换链或图层。缺省仍走原本地实现。

收益是 local／foreign 的后续迁移可以沿同一套资源生命周期处理，不需从一个正在使用的本地图层偷换 owner。代价是即使始终本地的实验调用也要承担 CAContext、host／lease／status、既有消息与 producer 观察 worker、250ms 恢复检查及合成开销。正式性能尚未测量，不能据功能通过默认采用；这项取舍是实验采用，产品采用仍待。回退为关闭开关或整体恢复匹配的前一引擎，不在同一运行中混配组件。

0029 只改变一个构造准入条件、移除不再使用的筛选函数，没有新增 HWND 缓存、改变 legacy ABI 或改动 coordinator 的许可／回收规则。源码复审未发现该增量具体 P1/P2，26 个实际代码输入和 24 个比较输入的精确哈希已读回；项目记忆仅列为上下文。Native 增量严格编译、配套链接、签名与完整 PE／Unix 布局核对完成，补丁零 fuzz／零 offset 重建为实际候选字节。

父代理在自己的限定实验准入后启动真实运行，独立源码报告随后完成；不把它记作独立审查后的运行。复用原有、逐字未改的窗口生命周期用例，两种位宽各 1,415 检查、4 窗口、56 交换链、168 Present，均零失败、CLI 零退出。实际 session 确认开关为 1，日志各观察 56 个真正导出的 context，均为 `hwnd == root`，原 legacy snapshot／detach／destroy 各 56 次。实验瓶原配置和 DLL 字节或缺失恢复、私有进程清理及四个保护摘要另经核对，见[证据](evidence/r-v1-unified-local-20261102.json)。

这个旧用例在最后毁窗后很快结束，只观察到 55 个本地 freed marker；有 1 份未在进程退出前取得独立释放见证。不能据进程正常退出推断 56 份均完成合作退役，也不直接把它定性为跨进程泄漏。下一专用往返用例将由 renderer 真正拥有初始 Root1／child，另一进程拥有 Root2，renderer 自己毁 child 后保持进程存活，直至全部实际资源许可和本地释放完成再 ACK／退出。

本项只是新策略的本地功能运行，未取本地窗口图像，尚未证明 local→foreign→local、resize、CEF、完整尾部回收、正式性能或游戏会话。原图形阶段继续；默认、门禁、HY 顺序和 Windows 条件保持。
