## 由真实观察发现的两个缺口

1. **宿主路径启动的安装器未列入进程扫描。** 安装器PID59083存活，内核进程信息指向Wine宿主，但argv[0]保留绝对Mac `.exe`路径。旧扫描器只接受第二字符为冒号的镜像，漏掉该程序。修正沿用UID、Wine executable、CIDER_BOTTLE/WINEPREFIX及PID身份检查，使用该进程自己的prefix映射绝对宿主`.exe`，其他loader仍需显式选项。标记用于合作进程归属，不声称隔离恶意进程。安装器在修正前已经退出，修正只有源码审查及构建证据，尚无该活进程的修后验收。
2. **外部删除瓶子后资料库残留。** CLI将本次瓶子移入废纸篓，GUI仍显示临时入口，手动刷新后恢复五个条目。FSEvents过滤原来没有识别直接瓶子目录事件；现在规范化路径并匹配受管根及其直接子项。没有将整个游戏资源树写入都作为刷新条件。修正已构建并装入本机App，尚未重复外部目录删除验收。

收益是让真实安装器纳入既有观察/停止链，并减少CLI与GUI目录状态不一致。代价是扫描宿主镜像时做路径映射、受管顶层目录变化可触发刷新。回退可分别撤回ProcessScanner和事件过滤改动；不需要改用户游戏文件或引擎。
