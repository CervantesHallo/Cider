# 不依赖确认结果决定资源释放的消费者

当前per-host阶段的有限消费者策略检查。复用112的原引擎及Native helper，测试适配器实际调用一次LIVE_INSTALL，把真实NT/操作返回记录给独立观察器，但不把结果字段交给消费者分支。消费者保留已知ticket、实际context和RO页，再通过新的纯snapshot观察真实模型，随后按ticket取消，等实际RO SAFE与模型归零后才释放。

双PE各25/0、CLI0，源审和独立raw/组件/清理绑定见research115。实际安装调用只发生一次，没有按回复重放。这个适配器没有修改任何NT返回值或产品代码。

**不是实际通信丢包或USER超时测试。** 真实安装结果仍由独立观察器记录；本用例只证明测试消费者的释放决定不使用那个结果。不能由它声称未知transport契约或关键NT故障并发已验收。
